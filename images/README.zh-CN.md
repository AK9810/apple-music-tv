# 图片

[English](README.md) | **简体中文**

根 README 引用的截图与素材。用下面这些确切文件名把你自己的截图放进来：

| 文件 | 画面 |
|------|--------|
| `now-playing.png` | 正在播放 —— 动态背景 + 逐词同步歌词（README 主视觉） |
| `listen-now.png` | 现在收听 / 首页（Top Picks） |
| `browse.png` | 浏览 |
| `library.png` | 资料库（侧栏 + 网格） |
| `search.png` | 搜索 —— 流派 / 心情磁贴 |
| `music-video.png` | 正在播放的音乐视频 |
| `category.png` | 分类 / 策展人页面 |
| `nowplaying.gif` | README 顶部的演示循环 |

在 Fire TV / Android TV 上截图：

```bash
adb exec-out screencap -p > shot.png
```

音乐视频及其他受 DRM/HDCP 保护的画面可能截出来是黑的 —— 必要时改用手机/相机拍摄。
